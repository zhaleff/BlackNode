# Waybar

## Configuration Structure

Waybar uses a three-level include system. The root `config.jsonc` points to a layout file, which includes an aggregator that pulls in all 31 individual module definitions.

- `config.jsonc` — position, height, margins, `reload_style_on_change`
- `Layouts/blacknode.jsonc` — module groups and their order
- `Modules/all_modules.jsonc` — includes all 31 `.jsonc` module files

This means you can swap the entire layout by changing one include, add/remove modules by editing the aggregator, or tweak a single module without touching anything else.

## The Layout

The bar is divided into visual clusters called "hollow groups." Each group has its own background, padding, and border-radius, creating distinct sections floating inside the pill-shaped bar.

**Left side:** distro icon, workspaces, privacy indicators (camera/mic/recording/DND), audio volume, pomodoro timer, package update counters.

**Center:** idle inhibitor toggle, clock with calendar tooltip.

**Right side:** media player controls (mpris with per-app colored icons), weather, network/bluetooth/backlight/battery, power button.

Groups at the far left and far right get asymmetric border-radius (32px on the outer side, 10px on the inner) to blend with the 999px-radius pill bar.

## Module Types

**Native modules** — built-in waybar functionality: battery (10-level icon array), clock (12h + alt date + calendar tooltip), network (5-signal WiFi icons), wireplumber (volume with Bluetooth awareness), workspaces (animated with bounce easing), temperature, CPU, memory, tray, idle inhibitor.

**Custom modules** — run a script, parse JSON output. Used when waybar's built-in doesn't cover the use case: bluetooth state, privacy indicators (camera/mic active detection), weather forecast, pomodoro timer, DND toggle, distro icon, package counts.

## Custom Scripts

Scripts under `Scripts/` are organized by function:

- **Privacy/** — camera detection (fuser on `/dev/video*`), microphone detection (pactl source-outputs), combined privacy indicator, recording detection (pgrep wf-recorder)
- **System/** — bluetooth state, distro detection, DND toggle, package/AUR update counts, pomodoro status, layout switcher, waybar restart
- **launcher/** — layout selector with profile-awareness (study/coding profiles get their own menus)
- **weather/** — Python script: IP geolocation, Open-Meteo API, 7-day forecast, 15-minute cache, WMO weather codes mapped to nerd font icons with color coding

## The Style

The bar itself is transparent with 999px border-radius (pill shape). Groups have `@surface` background with subtle outline border. Workspaces animate with a bounce easing curve (`cubic-bezier(.55, -0.68, .48, 1.682)`) — the active button overshoots its target size and springs back.

Battery has four visual states: normal, warning (yellow at 20%), critical (red at 15%, blinks when not charging), charging (green). Privacy modules turn red when active. Pomodoro uses green/yellow/running/paused/finished.

Tooltips use the same MD3 color tokens with 16px border-radius and subtle outline border.

## Colors

`colors.css` is generated by matugen from the current wallpaper. Tokens follow Material Design 3: primary, surface, on-surface, secondary-container, outline. These tokens are referenced in `style.css` and embedded directly in mpris player icons via `<span foreground="...">` for per-app coloring (Spotify green, Firefox pink, default purple).

## Signal System

The pomodoro module uses waybar's signal mechanism: `pomodoro-cli` sends `SIGRTMIN+10` to waybar to force an immediate update when the user starts/pauses/stops a timer, instead of waiting for the next 1-second interval.

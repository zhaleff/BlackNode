# The desktop in motion

## Hyprland in Lua

The main config is `~/.config/hypr/hyprland.lua`. It uses the `hl.*` API from Hyprland 0.55 and `require()` to load the modules under `settings/`, `animations/vertical.lua`, and `themes/colors.lua`.

The files that matter most:

- `settings/keybinds.lua` holds the keybinds, media keys, and mouse bindings.
- `settings/input.lua` sets `kb_layout = "us,es"` and natural touchpad scrolling.
- `settings/general.lua` sets the scrolling layout, gaps, and borders.
- `settings/layout.lua` configures the scrolling layout.
- `settings/decoration.lua` sets blur, rounding, and opacity.
- `settings/rules.lua` holds window and layer rules.
- `settings/autostart.lua` starts the session processes.
- `themes/colors.lua` is generated by `matugen`.

`general.lua` requires `themes/colors` a second time. Lua caches modules, so this does not run twice. If `themes/colors.lua` is missing, startup fails.

## Keybind grammar

`mainMod` is `SUPER`. The `bind()` helper prepends `SUPER +`. The same letters change function depending on the modifier:

| Combination | Action |
|---|---|
| `SUPER + h/j/k/l` | focus left/down/up/right |
| `SUPER + SHIFT + h/j/k/l` | move the window in that direction |
| `SUPER + ALT + h/j/k/l` | resize a floating window |
| `SUPER + CTRL + h/j/k/l` | move a floating window |

The layout is `scrolling`. Its own keys:

| Key | Action |
|---|---|
| `SUPER + .` / `SUPER + ,` | move the column right/left |
| `SUPER + -` / `SUPER + =` | shrink/grow the column width |
| `SUPER + A` | promote the window |
| `SUPER + T` | toggle fit |
| `SUPER + C` | fit active |
| `SUPER + SHIFT + C` | fit visible |
| `SUPER + Home` / `End` | fit to beginning/end |

Workspaces: `SUPER + 1..9` focuses, `SUPER + SHIFT + 1..9` moves. `SUPER + ]` and `[` go to the next/previous workspace; with `SHIFT` they move the window. `SUPER + TAB` returns to the previous workspace. `SUPER + S` toggles the `magic` scratchpad; `SUPER + ALT + S` moves the window there.

Window keys: `SUPER + Q` closes, `SUPER + F` toggles floating, `SUPER + SHIFT + F` toggles fullscreen, `SUPER + P` toggles pseudo-tiling.

Apps and scripts: `B` Firefox, `D` Kitty, `E` Dolphin, `Y` Spotify, `R` `rofi -show drun`, `SPACE` the BlackNode menu, `X` power menu, `G` screen recording, `W` wallpaper, `V` clipboard, `M` music, `ESCAPE` lock, `SHIFT + S` screenshots, `SHIFT + A` `pavucontrol`, `SHIFT + X` `wlogout -b 6`. `CTRL + ALT + UP` and `CTRL + ALT + DOWN` launch the Waybar scripts.

Media keys (`XF86Audio*`, `XF86MonBrightness*`) are marked `locked = true`. Volume and brightness repeat while held. The volume keys call `wpctl` and the OSD; mute also calls the OSD.

## The scrolling layout

`settings/general.lua` sets `layout = "scrolling"`. `settings/layout.lua` configures it:

- `fullscreen_on_one_column = true`
- `column_width = 0.99`
- `explicit_column_widths = "1.0, 0.5"`
- `focus_fit_method = 1`
- `follow_focus = true`
- `direction = "right"`

The `master` and `dwindle` blocks in other files do not change the session while the layout is `scrolling`. `master-layout.lua` is loaded, but it only matters if you change `general.layout` to `master`. If you come from classic tiling, opening a window here adds a column.

## Window rules

`settings/rules.lua` has rules by class. `clipse`, `imv`, `org.kde.dolphin`, `org.pulseaudio.pavucontrol`, and several dialogs float at fixed sizes. Kitty, Spotify, and Alacritty use opacity. Layer rules apply blur to Kitty, `logout_dialog`, Waybar, Rofi, and Alacritty, and remove animation from `selection` and `hyprpicker`.

To add a rule, find the real class with `hyprctl clients` and copy the pattern. Do not guess the class from the executable name.

## Startup, idle, and locking

`autostart.lua` starts `nm-applet`, Waybar, Hypridle, `awww-daemon`, Dunst, the `wl-paste` watchers for `cliphist`, the Bibata cursor, and the notification and weather scripts. It does not check whether the binaries exist. If something is missing, the command fails silently; run the script by hand in a terminal to see the error.

`hypridle` has four listeners:

| Time | Action |
|---|---|
| 300 s | brightness to 10% |
| 420 s | `loginctl lock-session` |
| 480 s | turn DPMS off |
| 900 s | `systemctl suspend` |

`hyprlock.conf` sources `~/.config/hypr/themes/hyprlang.conf`, uses the static `hyprlock.png` background, and shows the clock, date, `Hi, $USER`, the current track, and the weather. The lock screen weather is fixed to `13.67, -89.28` in `~/.config/hypr/scripts/weather.sh`. It does not use the Waybar geolocation. Change it if you live somewhere else.

`wlogout` has six buttons: lock, suspend, reboot, shutdown, logout, and hibernate. The layout is in `wlogout/layout`; the icons are in `wlogout/icons`.

## What the session assumes

The installer installs the `core` and `aur` groups. Several binaries used by the configs are outside those groups. The missing packages table in [firstBoot.md](firstBoot.md) lists the common gaps.

For session state, use `hyprctl systeminfo` and `journalctl --user -b`. If a keybind opens a terminal and nothing happens, check whether the executable exists before editing the bind.
